# Rumblevale: game design

A 2.5D roguelite brawler in the spirit of Little Fighter 2. It is a single HTML file with no assets: every sprite, background, icon, sound and song is generated by code at runtime. All characters are original.

## Pillars
1. **Punchy feel:** hit-stop, shake, squash and stretch, particles, and a sound for every action.
2. **A build every run:** level-up drafts of 3 cards, elemental spells that evolve, weapon tiers, and duo synergies.
3. **A world worth exploring:** a hand-drawn-style fantasy map where each node is a harder level with its own biome, jokes and secrets.
4. **Plays anywhere:** keyboard with LF2-style inputs, touch with a joystick and buttons, and a portrait or landscape layout.

## Core loop
World map → pick a node → choose a hero → **level** (3–4 arena sections of waves, then a boss or elite) → collect XP gems → level-up draft → win with 1–3 stars, or die keeping 60 % of quarters → spend quarters on the skill tree → back to the map.

## Controls
| Action | Keyboard | Touch |
|---|---|---|
| Move (x and depth) | WASD / Arrows | Left virtual stick |
| Attack | J / Z | **A** |
| Jump | K / X | **J** |
| Defend | L / C | **D** |
| Spell 1/2/3 | `D→A`, `D↑A`, `D↓A` (LF2 grammar), or U / I / O | Spell buttons |
| Overdrive | Space (meter full) | Star button |
| Run / dash | Double-tap a direction | Push the stick fully |
| Pause | Esc / P | Pause button |

## Elements and status effects
- **Fire:** burn (damage over time). Burning plus frozen gives **Steam Burst** (AoE).
- **Ice:** chill slows; 3 stacks freeze. A fire, earth or heavy hit on a frozen target **shatters** it for bonus damage.
- **Earth:** stun and knockdown, plus shockwaves.
- **Time:** slow field (enemies and projectiles at 35 % speed); Time Stop when evolved.
- **Storm:** chain sparks jump to nearby enemies.

## In-run upgrades (draft cards)
**Spells:** max 3 active, level 1 → 5, then evolution.

| Spell | Element | Evolves into |
|---|---|---|
| Fireball | Fire | Meteor Rain |
| Flame Pillar | Fire | Inferno Tornado |
| Ice Shard | Ice | Glacial Lance |
| Frost Nova | Ice | Absolute Zero |
| Earthquake | Earth | Tectonic Rage |
| Boulder Toss | Earth | Avalanche |
| Chrono Bubble | Time | Time Stop |
| Blink Strike | Time | Afterimage Army |
| Chain Lightning | Storm | Thunderstorm |

**Passives (relics):**
- Fire Aura, Orbiting Ice Shards, Thorn Skin, Vampire Fangs (lifesteal)
- Lucky Cartridge (crit), Turbo Boots, Coin Magnet, Second Wind, Combo Gloves
- Mana Crystal, Double Jump

**Weapon cards:**
- Sharpen: damage up.
- Reach: range up.
- Rhythm: attack speed up.
- Infusion: add an element to basic hits.
- Tier up at weapon level 3 and 6, which changes how the weapon looks.

**Duo cards** (need both elements):
- Steam Engine (Fire + Ice)
- Magma Core (Fire + Earth)
- Plasma (Fire + Storm)
- Permafrost Clock (Ice + Time)
- Tectonic Thunder (Earth + Storm)
- Déjà Vu (Time + Storm)

**Rarity:** common, rare, epic, legendary. Legendary odds rise with Luck.

## Meta: the Skill Tree (spend Quarters)
- **Might:** Iron Fists (+dmg), Crit Eye, Heavy Finisher, Berserker (low HP → dmg), Overkill Splash
- **Guard:** Thick Skin (+HP), Block Master, Quick Recovery, Milk Lover (healing ×), **Extra Life (1UP)**
- **Arcana:** Deep Pockets (+MP), Mana Flow (regen), Spell Echo (chance to cast twice), Head Start (start with a random spell), Elemental Lore (+element dmg)
- **Fortune:** Greedy (+quarters), Scholar (+XP), Reroll, Fourth Card (4-card drafts), Lucky Charm (rarity)

- **Elite modifiers:** Shielded, Swift, Vampiric, Explosive, Giant

## Special modes
- **Keyboard Warrior:** typing combat with a lesson ladder, see RESEARCH §5.
- **Endless Colosseum:** waves until you fall, with a local high score.
- **Overdrive** (in any fight): fill the meter by dealing damage, then trigger it. Time slows for everyone else, you glow gold, and damage is ×2 for 6 s.
